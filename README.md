# Site Hora do Dia
Esse site foi o exercício (parte 1) proposto pelo professor Gustavo Guanabara, referente ao seu curso de JavaScript no canal Curso em Vídeo. 

O site verifica as horas do computador do usuário e, de acordo com as horas, o site informará a hora atual e mudará o background e imagem. 
Exercício com objetivo de praticar tudo que foi ensinado até esse determinado ponto.
